# G0G // Dynamic 808 Synthesizer

A high-performance, monophonic C++ audio plugin designed to generate pitch-dynamic 808 basslines with advanced portamento glide architectures, multi-mode saturation modeling, and hard-hitting transient design. Built using the JUCE framework.

## Project Architecture

`G0G` uses a dedicated sub-surface synthesis model that splits the classic 808 voice into a high-frequency transient strike and a low-frequency sub-bass accumulator, processing the summed signal through a specialized inline saturation and filtering chain.

```
 [MIDI Input] ──────► [Portamento / Glide Unit] ───┐
```

## Core Synthesis & Processing Modules

### 1. The Sub Engine & Pitch Envelope
* **Oscillator:** A clean, single-cycle monophonic sine wave generator tracking MIDI note-on frequencies.
* **Transient Kick Emulation:** Upon note trigger, the oscillator frequency is subjected to an ultra-fast, exponential pitch envelope decay. Pitch scales from an offset (~ +24 semitones) down to the target root note within 20 - 40 ms to mimic the acoustic impact of a drum head.
* **Amplitude Contour:** Governed by an **AHD (Attack-Hold-Decay)** curve. The attack is fixed at 0 ms, followed by a brief, user-definable hold stage to maintain maximum energy before dropping into an exponential decay tail.

### 2. The Portamento Glide Unit
* **Logic:** When a note is triggered while a prior note is actively held, the synthesizer glides fluidly between frequencies instead of jumping abruptly.
* **Interpolation:** Implements a continuous, time-bounded exponential interpolator where the glide duration ($t_{\text{glide}}$) is exposed to the automation bus, allowing for dramatic pitch-bent slides common in modern low-end production.

### 3. The Click Engine (Transient Control)
* **Generator:** A tiny burst of white or pink noise synced precisely to sample zero of a note onset.
* **Filtering:** Passed through a steep, fixed 2-pole High-Pass Filter (800 Hz) to eliminate conflicting low frequencies.
* **Purpose:** Provides a consistent high-mid "knock" that ensures the 808 translates clearly on smaller playback systems without muddying the main sub register.

### 4. Multi-Mode Drive Stage (The Saturation Core)
The summed signal passes through a selectable mathematical waveshaping block to introduce rich harmonic distortion:
* **Tube Model (Asymmetrical):** Introduces even harmonics for warm, thick, traditional analog saturation.
* **Clip Model ($\tanh$):** Introduces aggressive odd harmonics to generate a hard, mid-range growl.
* **Foldback Model:** Inverts the signal peaks past a hard threshold to produce digital, industrial textures.

## Technical Specifications & Mathematical Models

### Portamento Interpolation Logic
The instantaneous rendering frequency $f(t)$ slides from the source frequency $f_{\text{source}}$ to the target MIDI frequency $f_{\text{target}}$ over a sample-count duration $T$ computed from the user's glide time parameter:

$$f(t) = f_{\text{target}} + (f_{\text{source}} - f_{\text{target}}) \cdot e^{-\left(\frac{5t}{T}\right)}$$

*Where $t$ increments every sample until $t = T$.*

### Post-Drive Filtering
To sculpt the raw high frequencies generated by the clipping algorithms, a 12dB/octave State Variable Low-Pass Filter maps down the spectrum:

$$H(z) = \text{SVF\_LPF}(X(z), f_{\text{cutoff}})$$

*Where $f_{\text{cutoff}}$ typical ranges between 400 Hz and 1.5 kHz to isolate the harmonic grit within the low-midrange.*

## Implementation Outline (JUCE Architecture)

### 1. Audio Processing Block (`PluginProcessor.cpp`)
* Maintain a `juce::Synthesiser` subclass configured strictly for a single, monophonic voice.
* Implement sample-rate tracking to ensure the glide rate coefficient and pitch-drop envelopes remain completely independent of the DAW's operating buffer size.
* Manage parameter smoothing via `juce::LinearSmoothedValue` to prevent audible digital clicks during high-drive parameter automation.

### 2. User Interface View (`PluginEditor.cpp`)
* Clean visualizer panel rendering the AHD amplitude curve alongside a visual slider for the glide time parameter.
* Standardized rotary sliders mapping to Drive, Cutoff, Transient Click Level, and Glide Speed.

## Compilation Requirements
