# G0G // Dynamic 808 Synthesizer

A high-performance, monophonic C++ audio plugin designed to generate pitch-dynamic 808 basslines with advanced portamento glide architectures, multi-mode saturation modeling, and hard-hitting transient design. Built using the JUCE framework.

## Project Architecture

`G0G` uses a dedicated sub-surface synthesis model that splits the classic 808 voice into a high-frequency transient strike and a low-frequency sub-bass accumulator, processing the summed signal through a specialized inline saturation and filtering chain.

```
 [MIDI Input] ──────► [Portamento / Glide Unit] ───┐
                            │                     │ (Frequency Curve)
                            ▼                     ▼
[Click Engine] ──────► [Sub Engine] ──────────────┴───► [Summing Bus]
(Filtered Noise)       (Monophonic Sine)                     │
                                                             ▼
                                                    ┌─────────────────┐
                                                    │ Waveshaper      │
                                                    │ (Multi-Drive)   │
                                                    └────────┬────────┘
                                                             │
                                                             ▼
                                                    ┌─────────────────┐
                                                    │ Shaper LP Filter│
                                                    │ (12dB/oct SVF)  │
                                                    └────────┬────────┘
                                                             │
                                                             ▼
                                                        [Audio Out]
```

## Core Synthesis & Processing Modules

### 1. The Sub Engine & Pitch Envelope
* **Oscillator:** A clean, single-cycle monophonic sine wave generator tracking MIDI note-on frequencies.
* **Transient Kick Emulation:** Upon note trigger, the oscillator frequency is subjected to an ultra-fast, exponential pitch envelope decay. Pitch scales from an offset (~ +24 semitones) down to the target root note within 20 - 40 ms to mimic the acoustic impact of a drum head.
* **Amplitude Contour:** Governed by an **AHD (Attack-Hold-Decay)** curve. The attack is fixed at 0 ms, followed by a brief, user-definable hold stage to maintain maximum energy before dropping into an exponential decay tail.

### 2. The Portamento Glide Unit
* **Logic:** When a note is triggered while a prior note is actively held, the synthesizer glides fluidly between frequencies instead of jumping abruptly.
* **Interpolation:** Implements a continuous, time-bounded exponential interpolator where the glide duration ($t_{\text{glide}}$) is exposed to the automation bus, allowing for dramatic pitch-bent slides common in modern low-end production.

### 3. The Click Engine (Transient Control)
* **Generator:** A tiny burst of white or pink noise synced precisely to sample zero of a note onset.
* **Filtering:** Passed through a steep, fixed 2-pole High-Pass Filter (800 Hz) to eliminate conflicting low frequencies.
* **Purpose:** Provides a consistent high-mid "knock" that ensures the 808 translates clearly on smaller playback systems without muddying the main sub register.

### 4. Multi-Mode Drive Stage (The Saturation Core)
The summed signal passes through a selectable mathematical waveshaping block to introduce rich harmonic distortion:
* **Tube Model (Asymmetrical):** Introduces even harmonics for warm, thick, traditional analog saturation.
* **Clip Model ($\tanh$):** Introduces aggressive odd harmonics to generate a hard, mid-range growl.
* **Foldback Model:** Inverts the signal peaks past a hard threshold to produce digital, industrial textures.

## Technical Specifications & Mathematical Models

### Portamento Interpolation Logic
Glide is interpolated in pitch (log-frequency), so a slide covers equal musical distance in equal time. The rendering frequency $f(t)$ moves from $f_{\text{source}}$ to $f_{\text{target}}$ over $T$ samples:

$$f(t) = f_{\text{target}} \cdot 2^{\,\log_2\left(f_{\text{source}} / f_{\text{target}}\right) \cdot s(t/T)}$$

where the shape $s$ blends a linear fall $1-r$ (curve = 0) with a normalised exponential $\dfrac{e^{-5r}-e^{-5}}{1-e^{-5}}$ (curve = 1), so both land exactly on the target.

---

### Post-Drive Filtering
To sculpt the raw high frequencies generated by the clipping algorithms, a 12dB/octave State Variable Low-Pass Filter maps down the spectrum:

$$H(z) = \text{SVF\_LPF}(X(z), f_{\text{cutoff}})$$

*Where $f_{\text{cutoff}}$ typical ranges between 400 Hz and 1.5 kHz to isolate the harmonic grit within the low-midrange.*

## Controls

| Panel | Control | What it does |
|---|---|---|
| SUB | MORPH / TUNE / FINE | Sub waveform (sine, triangle, square); transpose in semitones; fine tune in cents |
| GLIDE | LEGATO / TIME / CURVE | Retrigger or legato (overlapping notes slide without re-punching); portamento time and shape |
| PUNCH | DEPTH / SPEED | Starting pitch offset (semitones) and how fast it drops |
| AMP | GATE / HOLD / DECAY / SHAPE / REL | One-shot (rings its full decay) or gate (note length shapes the bass, fades over REL); AHD envelope and decay curve |
| CLICK | TYPE / LEVEL | Noise burst on each note (off, white, pink) |
| DRIVE | MODE / AMOUNT | Tube, clip or foldback saturation (2x oversampled) |
| FILTER | CUTOFF / SWEEP / SPEED | Post-drive low-pass, plus its envelope depth and decay |
| OUT | 2X/4X / VEL / VOL | Drive oversampling quality; velocity sensitivity (0% = every hit full level, like a real 808); master level (dB) |
| PERF | PITCH / MOD | Pitch wheel (+/-2 semitones) and mod wheel (opens the filter by up to 4 kHz) |

Hover any control title for a plain-English definition. Seven factory presets
(Classic 808, Long Boom, Distorted 808, Trap Slide, Short Kick, Foldback Growl,
Pure Sub) are also exposed to the host as programs; your own presets are saved
as `.g0gpreset` files in `~/Library/Application Support/G0G/Presets/`.

## Implementation Notes (JUCE Architecture)

### 1. Audio Processing (`PluginProcessor.cpp`)
* A single monophonic voice: `GlideUnit` -> `SubEngine` + `ClickEngine` -> `SaturationCore` -> SVF low-pass.
* MIDI is applied at its exact sample position; control updates (drive, filter, gain) run in 64-sample chunks, so output does not depend on the host buffer size.
* The filter envelope advances per sample; the cutoff is `base + envelope + mod wheel`.
* Velocity is normalised 0..1. Every trigger restarts the sub's phase, so each hit has the same attack.
* GATE mode fades the tail over REL when the last key is released; ONE-SHOT lets it ring. LEGATO slides overlapping notes without re-triggering.
* A fixed 20 Hz high-pass after the drive removes the DC the asymmetric tube mode creates; a soft limiter above 0.9 keeps the output within full scale.
* Decay tails are normalised so they reach exactly zero (no click when the voice ends).
* Drive runs through a 2x or 4x (selectable) polyphase IIR oversampler, with the matching latency reported, and is skipped entirely when bypassed.
* The square is band-limited (PolyBLEP): about 17 dB less aliasing than a naive square at B5.
* Parameter handles are cached; smoothers are primed on the first block to avoid a fade-in.

### 2. User Interface (`PluginEditor.cpp`, `G0GLookAndFeel.h`)
* Sectioned, resizable (aspect-locked) panels in a black-and-red scheme, with metal knobs, ribbed performance wheels and hover tooltips.
* The AHD / filter-envelope visualizer shows live playheads for the active note.
* `Presets.h` holds factory presets and user preset save/load.

## Install / Uninstall (macOS)

`installer/build_installer.sh` builds `dist/G0G-<version>-macOS.dmg` containing
a double-click installer package (VST3 + AU + standalone app), an *Uninstall
G0G* app, and a plain-language READ ME FIRST. It is unsigned by default;
Developer ID signing and notarization switch on via environment variables
(see the script header). Release tags attach the DMG automatically.

## Compilation Requirements
* **C++ Standard:** C++17 or higher
* **Framework:** JUCE 8.0.4 (fetched by CMake)
* **Targets:** VST3, AU, Standalone; universal macOS binary (Intel + Apple Silicon), macOS 14+
